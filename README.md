# Conversational Chatbot

A modern, clean conversational chatbot built with FastAPI, HTML, CSS, and Vanilla JavaScript.

## Features
- **Frontend**: Clean, modern dark theme UI with rounded chat bubbles and typing indicators.
- **Backend**: Fast and async REST API using FastAPI.
- **Modular Logic**: The LLM interaction logic is separated into `llm_service.py`, making it easy to swap in a real API like Gemini in the future.

## Prerequisites
- Python 3.8+
